# Third-party components

The project's original source code is licensed under [MIT](LICENSE). Third-party packages, model weights, runtimes and tools retain their own licenses. Installing a dependency does not change its license to MIT.

## Software dependencies

JavaScript versions are recorded in [package.json](package.json) and [pnpm-lock.yaml](pnpm-lock.yaml). Python versions are recorded in the `services/ai/requirements-*.lock` files. Refer to the installed packages' LICENSE/NOTICE files and upstream projects for the terms of each version. Preserve those notices when redistributing bundled dependencies.

Major upstream components include [NestJS](https://github.com/nestjs/nest), [Next.js](https://github.com/vercel/next.js), [React](https://github.com/facebook/react), [Prisma](https://github.com/prisma/prisma), [Better Auth](https://github.com/better-auth/better-auth), [BullMQ](https://github.com/taskforcesh/bullmq), [Redis](https://github.com/redis/redis), [PostgreSQL](https://www.postgresql.org/about/licence/) and [pgvector](https://github.com/pgvector/pgvector).

FFmpeg is obtained through `ffmpeg-static` or an explicit `FFMPEG_PATH`. Its distribution and enabled codecs have their own license terms; consult the exact binary's upstream notices before redistributing it. Docker Desktop has separate subscription/license terms and is not part of this repository.

## Publication format and demonstration

`vendor/mvs-publication-format-1.0.0.tgz` is this project's versioned publication-contract package. Its version and checksum are pinned in [vendor/publication-contract.json](vendor/publication-contract.json). It is retained as the installable contract artifact, not as a bundle of user publications.

The README screenshot shows a project-owned geometric drawing and test text generated by [scripts/fixtures.py](scripts/fixtures.py). No third-party manga pages, user recordings, model weights or generated speech are distributed in the repository.
